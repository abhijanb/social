# Social – Full-Stack Social Network

Monorepo with two independent apps: `back/` (NestJS + Prisma) and `front/` (React + Vite). No root package – run each app separately.

## Stack

**Backend** `back/` – Node `bun@1.3.14`, `typescript@6.0.3`
- NestJS `11.x`, `prisma@7.8.0` with `@prisma/adapter-pg` (PostgreSQL), `zod@4.6.4` validation, `bcrypt@6.0.0`, `jsonwebtoken@9.0.3`, `cookie-parser@1.4.7`
- Prisma Client generated to `back/src/generated/prisma` (`runtime = bun`)

**Frontend** `front/` – `vite@8.3.0`, `react@19.2.8`, `react-router-dom@7.18.3`
- Redux Toolkit `2.12.0` + RTK Query, `react-hook-form@7.88.0` + `zod`, `tailwindcss@4.3.3`, `typescript~6.0.2`

**DB** PostgreSQL (see `back/.env` `DATABASE_URL`)

## Database Schema `back/prisma/schema.prisma:11-43`

```prisma
model User { id String @id @default(cuid()); username String @unique; password String; sentRequests/ReceivedRequests Friendship[] }
model Friendship { id String @id @default(cuid()); requesterId, addresseeId String; status FriendshipStatus @default(PENDING); @@unique([requesterId, addresseeId]) }
enum FriendshipStatus { PENDING ACCEPTED BLOCKED }
```

## Features Built

### 1. Authentication
- Register and login with username and password
- Passwords are hashed before storage
- JWT is stored in httpOnly cookie and sent automatically with requests
- Logout clears the cookie and protected pages redirect to login

### 2. User Search with Self-Exclusion
- Dedicated search page at `/` for authenticated users – search any user by username
- Live results as you type with 300ms debounce to avoid excessive requests
- Case-insensitive matching that finds partial usernames
- Your own profile is automatically excluded from results – you never see yourself in search
- Shows up to 10 most recent matches with clean empty state when nothing is found

### 3. Users Management
- View list of users
- View single user profile
- Update user details
- Delete user

### 4. Friendship / Friend Requests
- Send friend request to another user (cannot add yourself)
- View pending requests (sent and received)
- Accept or reject incoming requests
- List accepted friends
- Handles already friends, blocked, and duplicate request cases

### 5. Username Suggestions — IB Highlight ⭐
> **Interview Board Point:** Smart conflict-resolution UX – instead of generic “username taken” error, backend proposes 3 available alternatives instantly.

- When a username is already taken during registration, the system suggests 3 available alternatives
- Suggestions are generated by adding numbers to the desired name (e.g., alex → alex1, alex2, alex3)
- Suggestions respect length limits and are checked in a single database query
- One click on a suggestion fills it into the form

## API Endpoints

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| POST | /user | no | register, sets `token` cookie |
| POST | /user/login | no | login, sets `token` cookie |
| POST | /user/logout | cookie | clears cookie |
| GET | /user?search= | cookie (optional) | search, excludes self if JWT present |
| GET | /user/:id | - | findOne |
| PATCH | /user/:id | - | update |
| DELETE | /user/:id | - | remove |
| POST | /friendship | - | create request |
| GET | /friendship?userId= | - | friends list |
| GET | /friendship/pending?userId= | - | pending both directions |
| PATCH | /friendship/:id | - | update status |
| PATCH | /friendship/:id/accept | body `userId` | accept |
| DELETE | /friendship/:id | - | remove |

## Setup

**Prereqs:** `bun@1.3.14`, PostgreSQL.

**Backend** `back/.env`:
```
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/social?schema=public"
JWT_SECRET="dev-secret-change-me-please-set-strong-secret"
JWT_EXPIRES_IN="7d"
```
```bash
cd back
bun install
bun run db:generate
bun run db:migrate   # or db:push
bun run db:seed
bun run dev          # http://localhost:3000
bun run build
```

**Frontend** `front/.env` (optional):
```
VITE_API_URL=http://localhost:3000
```
```bash
cd front
bun install
bun run dev          # vite default http://localhost:5173
bun run build
```

No `bun install` at repo root – apps are independent (root `package.json` removed).
